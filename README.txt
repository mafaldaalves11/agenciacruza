# Agência Cruza — Website
Website institucional em HTML, CSS e JavaScript.

Ficheiros:
- index.html
- style.css
- script.js
- logo.png

Para editar:
- Substituir os placeholders de equipa por fotografias e nomes reais.
- Substituir os projetos de exemplo por trabalhos reais.
- Alterar email/Instagram na secção Contactos.
- Ligar o formulário a um serviço de envio antes de publicar.
